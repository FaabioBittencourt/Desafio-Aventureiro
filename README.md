# Desafio Aventureiro ⚔️

Esta é a minha solução para o Desafio do Aventureiro, desenvolvido como parte dos meus estudos em Linguagem C.

## 📋 Sobre o Projeto
 O objetivo deste projeto é utilizando estruturas de repetição e condicionais em C. Criação de cartas com variaveis, apresentando-as para o usuario, também simular a movimentação de um personagem em um tabuleiro.

## 🚀 Tecnologias Utilizadas
* Linguagem C
* Compilador GCC (ou ferramenta, como VS Code)

## 🛠️ Como Executar o Projeto

Para rodar este projeto localmente, você precisa ter um compilador C instalado.
