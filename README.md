# Desafio Aventureiro ⚔️

Este repositório contém a minha resolução para o Desafio do Aventureiro, focado no desenvolvimento de jogos e lógica em Linguagem C.

## 📋 Sobre o Projeto
O projeto consiste na implementação de lógicas de jogos clássicos utilizando conceitos fundamentais de programação:
* **Xadrez:** Lógica e movimentação das peças de xadrez no tabuleiro.
* **Super Trunfo:** Sistema de comparação de cartas e atributos.
* **Nível Avançado:** Implementações e desafios com estruturas mais complexas.

## 🚀 Tecnologias Utilizadas
* **Linguagem C**
* Estruturas de repetição (Loops) e condicionais (If/Else)

## 🛠️ Como Executar o Projeto

Para rodar os códigos localmente, você precisa de um compilador C (como o GCC) instalado.
