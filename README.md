# Desafio Aventureiro ⚔️

Esta é a minha solução para o Desafio do Aventureiro, desenvolvido como parte dos meus estudos em Linguagem C.

## 📋 Sobre o Projeto
O objetivo deste projeto é utilizar estruturas de repetição e condicionais em C. Apresentando cartas conforme as variaveis descritas no inicio do projeto, verificando o que o usuario escolheu.

## 🚀 Tecnologias Utilizadas
* Linguagem C
* Compilador GCC (ou ferramenta, como VS Code)

## 🛠️ Como Executar o Projeto

Para rodar este projeto localmente, você precisa ter um compilador C instalado.
